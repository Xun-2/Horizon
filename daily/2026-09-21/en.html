Background

AI model weights are large files commonly distributed through centralized repositories such as Hugging Face, which can become unavailable if a host removes them or access is disrupted. Peer-to-peer torrents divide files among many participants and can use checksums to verify that downloaded weights match the original model, reducing dependence on any single host.

Community Discussion

Commenters generally supported torrent-based model distribution as a way to avoid a single hosting failure point, citing earlier use of peer-to-peer delivery for games. Discussion of uncensored models was more technical: one commenter argued that runtime activation orthogonalisation can provide the same effect as modifying weights while distributing much less data.
