HN.watch Generates On-Demand HTML Explainer Videos

HN.watch is a Hacker News-style site that uses Scrimba Explain to generate HTML-based explainer videos for linked posts when a user first clicks them. Scrimba says videos can begin playback within a few seconds and cost about $0.04 each, excluding image generation, which can substantially increase costs.

Details and sources

HN.watch is a Hacker News-style site that uses Scrimba Explain to generate HTML-based explainer videos for linked posts when a user first clicks them. Scrimba says videos can begin playback within a few seconds and cost about $0.04 each, excluding image generation, which can substantially increase costs. The format is less visually sophisticated than diffusion-based video, but it is designed to be inexpensive, fast, and easy to edit with AI assistance. The system is built with the open-source Imba language, Scrimba's OP sync engine and Q agent context-management system, and models including Gemini, GPT, Inworld, and ElevenLabs.

Summary

HN.watch is a Hacker News-style site that uses Scrimba Explain to generate HTML-based explainer videos for linked posts when a user first clicks them. Scrimba says videos can begin playback within a few seconds and cost about $0.04 each, excluding image generation, which can substantially increase costs. The format is less visually sophisticated than diffusion-based video, but it is designed to be inexpensive, fast, and easy to edit with AI assistance. The system is built with the open-source Imba language, Scrimba's OP sync engine and Q agent context-management system, and models including Gemini, GPT, Inworld, and ElevenLabs.

Background

Unlike pixel-based video generators, HTML-based video uses web technologies and code to render scenes, allowing content to be generated and modified quickly. Scrimba developed this approach for coding education and is applying it to article explanations, documentation, pull requests, courses, and personal content through a web interface and integrations including MCP, ChatGPT, and a Chrome extension.

Impact

The claimed cost and generation time could make short, on-demand explainers practical for documentation, software development workflows, and people who prefer listening or watching over reading.

Community Discussion

Commenters generally viewed the project as technically impressive and potentially useful, while noting that many users still prefer text and that generated videos can feel monotonous because of repetitive AI voices. One commenter described an open-source framework for more advanced voiceover synchronization and scene editing, while another said summary videos helped them consume technical articles when they were tired of reading.
