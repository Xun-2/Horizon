Strata Runs 125B Qwen Model on RTX 4090

Strata reportedly runs the 125B Qwen 3.8 Flash Next model locally on consumer hardware using aggressive quantization. One user measured 124 tokens per second on an Nvidia RTX 4090 with 128 GB DDR5 memory and a Ryzen 7950X3D, although the item title’s “100T/s” wording is inconsistent with the reported tokens-per-second figure.

Details and sources

Summary

Strata reportedly runs the 125B Qwen 3.8 Flash Next model locally on consumer hardware using aggressive quantization. One user measured 124 tokens per second on an Nvidia RTX 4090 with 128 GB DDR5 memory and a Ryzen 7950X3D, although the item title’s “100T/s” wording is inconsistent with the reported tokens-per-second figure. The result suggests that very large models can achieve fast local inference without data-center GPUs, but no source content was supplied to explain Strata’s implementation or independently validate its performance. Quantization below four bits may substantially reduce output quality, and one small vision test found much larger coordinate errors with Strata than with llama.cpp using the same model and adapter weights.

Background

Qwen3.8-Flash-Next is a 125-billion-parameter mixture-of-experts model that activates about 6 billion parameters per token, reducing inference compute compared with using every parameter. Strata uses 2-bit and 3-bit quantization to fit the model on gaming PCs with a single 12–24 GB NVIDIA GPU, at least 64 GB of system RAM, and a desktop CPU.

Impact

Strata could make a 125B sparse model practical for local inference on consumer GPUs, but aggressive quantization and reported vision-quality regressions may limit its reliability for precision-sensitive tasks.

Community Discussion

Commenters welcomed the speed but questioned whether sub-four-bit quantization preserves enough quality for demanding work; others reported strong results from four-bit deployments on RTX Pro 6000 hardware. A 50-image benchmark reported median coordinate error of 154.8 pixels with Strata versus 46.5 with llama.cpp, reinforcing calls for broader quality testing before accepting the performance claims.
